A small static blog

Plain HTML, quiet Tufte styling, and margin notes that wake up on scroll.

This site is deliberately small. There is no build step, no client-side router, and no component framework. Each page is a normal HTML file, and the visual system lives in one CSS file.

The layout borrows the useful parts of Tufte CSS: generous reading space, serif type, restrained links, and notes in the margin for asides that belong near the text.
